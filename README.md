A responsive hero section for a SaaS business landing page, built with vanilla HTML, CSS, and JavaScript. Designed for "Teamlo," a fictional product management platform, with a headline, CTA buttons, and a dashboard preview mockup.

**[Report Bug](https://github.com/NSniha/Business-Hero-Landing-page/issues)**

## Preview

<image src="/assets/preview.png">

## Features

- Responsive navbar with a slide-in mobile menu
- Hero section with headline, subtext, and dual CTA buttons (`Start for free`, `Get Demo`)
- Dashboard preview image with an animated gradient fade at the section base
- Icon set powered by Ionicons
- No frameworks or build step — plain HTML/CSS/JS, runs anywhere

## Tech Stack

- HTML5
- CSS3 (custom properties, Flexbox)
- Vanilla JavaScript (mobile nav toggle)
- [Ionicons](https://ionic.io/ionicons) for UI icons
- Google Fonts — Work Sans

## Getting Started

No build tools required.

```bash
git clone https://github.com/NSniha/Business-Hero-Landing-page.git
cd Business-Hero-Landing-page
```

Then open `index.html` in your browser, or serve it locally:

```bash
npx serve .
```
